---
description: First-time setup - choose a task source, optional MCP servers and environment, and write dev-factory.config.json (usage /dev-factory:setup)
---

You set the factory up for this repository with a person. Nothing here needs an account the person does not already use, and every question has a working answer that needs no tracker and no MCP server. Never write a secret into a file other than `~/.dev-factory/.env.local`.

1. Look first: `node "${CLAUDE_PLUGIN_ROOT}/scripts/config.mjs" validate`, `ls dev-factory.config.json .mcp.json 2>/dev/null`, `gh repo view --json nameWithOwner 2>/dev/null`, `git remote -v`, the repository's default branch (`node "${CLAUDE_PLUGIN_ROOT}/scripts/worktree.mjs" default-branch`), its test command and CI. Tell the person what you found in two lines.
2. Ask one question at a time, each with your recommendation:
    - **Where will it run?** On this machine only (launchd on a Mac), in Claude Code on the web, on a GitHub Actions schedule, or a Claude Code routine. For anything but this machine, run `node "${CLAUDE_PLUGIN_ROOT}/scripts/cloud.mjs" init` (add `--github-actions` or `--routine`) after the config is written; it commits the marketplace and enabled plugins to `.claude/settings.json` so cloud sessions install the plugin themselves. Say what changes there: no Docker or simulator unless the runner has them, a `github`, `notion` or `jira` task source (a `local` source only sees committed task files), and `git.worktreeRoot` if the checkout's parent folder is read-only.
    - **Where do tasks live?** `local` (markdown files in the repository, no account), `github` (Issues via `gh`, no MCP server, recommended when the repository is on GitHub), `notion` (a database; needs a Notion integration token and the Notion MCP server), `jira` (needs a Jira API token and the Atlassian MCP server). Details: `skills/task-source/`.
    - **What do they need to build a task?** The test command, whether there is a web UI to walk (Playwright), a mobile app (Maestro), a docker compose environment (`environment.type` `compose`, with its service, setup commands and ping URL) or neither (`none`, tests run on the host).
    - **Telemetry?** Sentry or Axiom for bug triage and post-merge validation. Skippable; bugs are then triaged from the task and a reproduction.
    - **Branches and PRs:** the base branch (default: the repository's), the branch types, size and area labels. Skippable; the defaults work.
3. Write only the keys that differ from `config.json` into `dev-factory.config.json` at the repository root (it merges over the defaults), for example `{"tasks": {"source": "github"}, "git": {"baseBranch": "main"}}`. If the repository's UI paths differ from the defaults, write `dev-factory.qa.yaml` (same shape as `qa/profiles.yaml`).
4. Enable MCP servers only for what was chosen: `node "${CLAUDE_PLUGIN_ROOT}/scripts/mcp.mjs" recommend` lists suggestions; `node "${CLAUDE_PLUGIN_ROOT}/scripts/mcp.mjs" enable <id>...` writes them to `.mcp.json`. For one step that enables the recommended set (or everything with `--all`) and then lists which servers are connected, need a `/mcp` login or need a restart, run `node "${CLAUDE_PLUGIN_ROOT}/scripts/mcp.mjs" connect`.
5. Prepare the source: `node "${CLAUDE_PLUGIN_ROOT}/scripts/tasks.mjs" init` (creates the labels or the folder; for notion and jira, say what to create by hand).
6. Run `node "${CLAUDE_PLUGIN_ROOT}/scripts/config.mjs" validate` and `bash "${CLAUDE_PLUGIN_ROOT}/scripts/doctor.sh"`; report each FAIL and warn with its fix. Do not edit anything the doctor flags without asking.
7. Make `dev-factory` available in the person's own terminal: show the plan with `bash "${CLAUDE_PLUGIN_ROOT}/scripts/install.sh"`, and on a yes run `bash "${CLAUDE_PLUGIN_ROOT}/scripts/install.sh" --apply` (it writes `~/.dev-factory/bin/dev-factory`, the machine's env file and, on a Mac, the launchd jobs only with `--load`). Tell them to add `~/.dev-factory/bin` to PATH.
8. Finish with the next step: `/dev-factory:plan "<idea>"` to create tasks, `/dev-factory:quick "<change>"` for a small change with no task, or `bash "${CLAUDE_PLUGIN_ROOT}/scripts/install.sh" --apply --load` to schedule unattended passes on this Mac.
