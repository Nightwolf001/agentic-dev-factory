# Improvement plan

Proposals for changing the factory itself, written by `/dev-factory:improve` from the run records, merged learnings and blocked or regressed tickets. It is a list for a person to decide on: improvement issues carry the label `dev-factory-improvement`, never `dev-factory`, so the factory does not build changes to itself unattended. A person reviews each draft PR and merges it.

The weekly scan keeps this table current. A finding needs at least `improvement.minEvidence` occurrences across different tickets.
